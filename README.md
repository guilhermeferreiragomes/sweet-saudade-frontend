## 📝 About the Project

**Sweet Saudade** is a modern, fluid, and fully responsive web application developed to promote and manage orders for a traditional Portuguese pastry and savory snack business (featuring iconic treats like Pastéis de Nata, Bolas de Berlim, and homemade Rissóis).

The main focus of this project was to combine a **premium and affective user experience (UI/UX)** with clean code architecture and a highly efficient **Serverless** approach, capable of solving real-world problems for a small business without fixed server costs.

---

## 🚀 Key Features

* **🛒 Dynamic Order Form:** Smart product and package selection system with automatic price calculation and quantity control prior to submission.
* **⚡ Serverless Data Flow:**
    * **EmailJS:** Immediate order notification emails sent to both the administrator and the customer.
    * **Google Apps Script API:** Synchronous and automated recording of all orders and reviews into a centralized **Google Sheets** database.
* **✨ Fluid & Animated UI:** Interface rich in interactions using **Framer Motion** for micro-animations, **Swiper** for touch-friendly carousels, and **React Fast Marquee** for dynamic informational banners.
* **🍪 Consent Management:** Integrated Cookie banner that restricts form actions until the user accepts the privacy policies, ensuring compliance with security best practices.
* **🛡️ Anti-Spam Protection:** Integration with **Google reCAPTCHA v2** to mitigate automated bot submissions.
* **📊 Web Analytics:** Real-time monitoring through **Google Analytics 4 (GA4)**, capturing pageviews and critical custom events (such as conversion clicks on the order button).

## 🛠️ Tech Stack

### Frontend Core
* **React 19** - Base library for building the modular, component-driven interface.
* **Vite** - Ultra-fast build tool and development environment.
* **React Router Dom 7** - Route management and SPA (Single Page Application) navigation.
* **Custom CSS** - Modern layouts built from scratch with **CSS Grid** and **Flexbox**, ensuring total control over responsiveness (Mobile-First) without relying on third-party utility frameworks.

### Animations and UI Components
* **Framer Motion** - Micro-interactions and state-based SVG animations.
* **Swiper & React Fast Marquee** - Touch sliders and high-performance continuous marquee effects.
* **SweetAlert2** - Aesthetic modals for success and error feedback upon data submission.

### Services & Integrations
* **EmailJS** (Client-side email processing).
* **Google Apps Script Web App** (Bridge to Google Sheets).
* **Google reCAPTCHA v2** (Security).
* **React GA4** (Product and behavioral metrics).
